## The line

> I paid extra for a fridge that talks. It only says two things: 'door open' and 'you again?'

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), after checking it is one non-empty line of 1–160 characters.

```sh
node main.ts
```
